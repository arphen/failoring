./garment - make garments for the Failoring mannequin (guide: docs/GARMENT_RECIPES.md, examples: garments/)

  ./garment body [--body B]                 body variables for recipe expressions (girths, heights, metres)
  ./garment list                            garments in the library
  ./garment export ID [--body B]            a library garment as a plan (JSON), to borrow shapes from
  ./garment check FILE [--body B]           expand a recipe: pieces, edges (index=name length), seams, ERRORs
  ./garment drape FILE [--body B] [--walk]  quick check on a coarse mesh: seams close, nothing falls off, OK/ERROR
  ./garment shots FILE [--body B] [--quality ultra|fine]  the real drape (1.5 cm mesh, GPU): photos + where pieces hang
  ./garment install FILE                    put it in the editor's library
  ./garment wear FILE                       install it and put it on the mannequin in the running editor
  ./garment editor                          start the editor (the user watches the mannequin there)

B: mine (the user's measurements, default) or average, petite, tall, curvy, plus, athletic.
Loop: write garments/NAME.json -> check -> drape -> shots (look at them) -> fix -> wear.
