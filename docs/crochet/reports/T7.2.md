# T7.2 — Crochet scene skeleton (§8.2)

## What was built

* `godot/crochet/crochet.tscn` + `crochet_main.gd`: the scene, built in code. Top bar (Scene: hook/peg or hand/pin, Load:
  empty / MacBook Air 13 / Pro 14 / Pro 16 / phone-sized box, Run, Stop, Compare (disabled until §9.3), camera buttons, Back to
  editor); left pane with the pattern `CodeEdit` (highlighting: stitch names, numbers, `#` comments, `#!` lines), the summary
  line, the error line, yarn / hook / tension and a bundled-patterns dropdown plus Open / Save as; centre 3D view (the studio, an
  orbit camera, the cloth mesh, the load box and the peg); right tabs Chart (placeholder until §9.1) and Metrics (the §7.5 table
  with the "UNVERIFIED starter values" notice).
* Live compile 0.4 s after the last keystroke on a worker thread; errors become a red line background and a message under the
  editor; the run button is disabled while the pattern does not compile. The simulation is the C++ `CrochetScene`, stepped by
  small jobs on a worker thread (job size adapts to about 150 ms), the view refreshed between jobs. Headless runs step
  synchronously (`FL_THREAD=1` forces the worker).
* `godot/tests/crochet_scene_check.gd/.tscn`.

## Measured

`godot --headless --path godot res://tests/crochet_scene_check.tscn`: **15 PASS, 0 failed** (66 s): the scene loads, the pouch
compiles on start ("1380 stitches, 40 m of yarn, 22 g, layout 10.3 x 15.7 cm"), the editor holds the pattern, a bad pattern gives
an error and disables Run, `start_run` is refused without a compiled pattern, 200 frames give 1250 finite vertices shown at the
hang height, the phase label reads `hang`.

## Notes / honest limits

* Nothing here was looked at on screen: the only environment was headless, whose dummy renderer cannot fill meshes (the view code
  is skipped there; tests read the vertices the view is given). The layout, highlighting colours and camera feel are the part a
  person has to look at on the Mac: `make run`, then the "Crochet" button (added in T7.3).
* An error with line -1 (CrochetPARADE's position-not-found) shows as "line -1" and gets no red line.
