# T6.4 — `crochet_cli` + PNG snapshots (§7.1)

## What was built

* `crochet/run.hpp`, `crochet_run.cpp` (new): `runCrochet(RunOptions)`, the whole headless pipeline in one call: import
  the pattern (the committed export next to it, or `node tools/crochet/cp_export.mjs`), build the model, lay it out, relax,
  hang (hang_pin / hang_peg / auto = by the strap when there is one), fit-check and insert a load, metrics, then write
  `<prefix>.json`, `.obj` (a `# stitch <id> row <r>` comment before each vertex), `_rest.obj` (the relaxed zero-g shape),
  `.png`, `_rest.png`. Exit code 0 settled, 2 not settled, 1 error.
* `crochet_core/cli/crochet_cli.cpp` (new): the command line wrapper (`crochet_cli` target).
* `snapshot.cpp`: the PNG writer now compresses (filter Sub + fixed-Huffman deflate with a distance-3 match): a snapshot
  went from 1.5 MB to 36-150 KB.
* `metrics`: `corner_angle_deg` is `null` when there is no face on both sides of the base-to-wall row (a flat disc).
* `tools/crochet/run_fixtures.sh`: runs the fixtures through the tool into `docs/crochet-shots/`.
* `test_crochet_cli.cpp` (new): runCrochet files and the OBJ/PNG contents (with an independent PNG reader), the tool's exit
  codes, every relax-only fixture through the tool, the pouch (exit 0, exit 2 when cut off after one frame). ~3 min.

## Measured

* All five relax-only fixtures (circle +5/+6/+8, tube40, facing) run from the tool with exit 0 and write 36-151 KB snapshots
  (`docs/crochet-shots/<name>.png`, `<name>_rest.png`, `<name>.json`).
* Exit codes: no pattern, missing pattern, unknown scene / load / yarn / option, a scene without a strap: exit 1;
  pouch cut off after one frame: exit 2; pouch `--scene hang_pin`: exit 0, drop 38.x cm and strap 47.4 cm in the JSON.
* OBJ of circle_plus6: 217 vertices, 384 faces, 217 stitch comments, the rest OBJ identical in structure.
* The pouch and the five bags run through the tool with the MBA13 load as part of T6.5 (the five-variant report): their
  snapshots and JSONs are committed with it. (The OBJ files are not committed: `.gitignore`.)
