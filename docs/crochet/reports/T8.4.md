# T8.4 — Compare and the five-variant run (§9.3)

**Compare** (button in the top bar) opens `godot/crochet/crochet_compare.gd`, an overlay with its own 3D view and a metrics table.

* **A / B**: A is the pattern in the editor with the panel's yarn, hook and tension; B is the same pattern, or any bundled pattern, with
  its own yarn and hook ("same as A" / 0 = the same). "Run A and B".
* **Hinge-round variants (5)**: the laptop bag with a plain, BLO, FLO, sl st round and a surface sl st row (the five bundled
  `bag_round_*` fixtures, with the yarn and hook of the panel; the plan's report used cotton worsted on 4.5 mm, so set that first).
* Both use the scene and the load of the top bar. Each piece runs on its own worker thread (compile, build, then steps in chunks near
  200 ms); up to `max(1, cores - 3)` run at the same time, so the plan's "sequentially" became parallel; the rest queue. Stop ends them.
* The pieces hang side by side 0.5 m apart in the studio, each with a label; the table has A, B and B - A for two pieces and one
  column each for more. The key rows (corner angle, base sag, drop, strap elongation, mass) are bold when the pieces differ in them
  (by more than 2 %, or 0.05 for small numbers). A piece that does not compile fails alone with its message.
* Shared with the main view: `godot/crochet/crochet_cloth.gd` (two-shell mesh, fibre look, box and peg), which the main script now uses too.

  is there; a piece that does not compile fails alone; the five variants are the five fixtures in a row 0.5 m apart, all run, and the
  table has five corner angles (168.8, 130.9, 163.3, 145.5, 163.9 deg after 4 frames). The threaded path too: two pouches on their own
  threads reach 20 frames after 5 s, the status line names each piece's phase, and Stop ends both with their numbers.
* `crochet_scene_check` 70 PASS and `crochet_api_check` 26 PASS unchanged after the move to `crochet_cloth.gd`.
* Mutations caught: nothing is ever bold (2 checks), every piece at the same place (2 checks).
* Screenshot (real renderer): `docs/crochet-shots/ui/compare_variants.png` (five bags after 10 frames).

## Notes

* The test steps each piece only a few frames, because a bag takes minutes to relax and hours with the laptop (see T6.5): the numbers
  in the table are not physical there; they check the plumbing (five runs, five corner angles). The physical five-variant numbers are
  the CLI runs of T6.5.
* The thread test does not run a piece to its end (a pouch is about 430 frames); it stops them. Running to the end is the same code as
  the main view's run and the CLI.
