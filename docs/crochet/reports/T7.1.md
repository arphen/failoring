# T7.1 — GDExtension `CrochetPattern`, `CrochetScene` (§8.1)

## What was built

* `crochet/session.hpp`, `crochet_session.cpp` (new): `CrochetSession`, the whole run as a **stepper** (relax -> hang -> insert ->
  release -> done) with `step(n)`, positions, metrics, the fit and load/peg data. `runCrochet` (the CLI) is now this class run to
  the end, so the editor and the tool share all of §7. Supporting refactors: `RelaxRun` (relaxModel in steps),
  `CrochetScene::advance`, `RigidLoad::insertSteps / releaseSteps`, `Metrics::entries()` (toJson is its formatter).
* `gdextension/src/crochet_bindings.{h,cpp}` (new), registered in `register_types.cpp` and linked with `crochet_core`:
  * `CrochetPattern`: `compile(text, yarns_path)` (runs `node tools/crochet/cp_export.mjs`, PATH widened for Homebrew; `#!`
    lines are read from the same text), `get_errors()`, `get_summary()` (stitches, rows, links, yarn_m, mass_g, skeins, vertices,
    faces, layout size, has_strap, fold_after_row), `get_chart()` (per stitch: id, piece, row, index, type, insertion (RS), written,
    facing, line, targets, layout x/y, in_mesh; rows; links), `set_yarn / set_hook / set_tension / set_tools_dir`,
    `get_yarn_ids / get_yarn_info`.
  * `CrochetScene`: `build(pattern, scene, load)`, `relax_step(n)`, `step(n)`, `phase()`, `is_done / is_settled`,
    `get_positions / get_indices / get_normals / get_stitch_of_vertex`, `get_metrics()` (all 31 keys, `null` where not
    applicable), `get_load_transform / get_load / get_peg`, `get_error()`.
* `godot/tests/crochet_api_check.gd/.tscn`: compiles the pouch, checks the counts, builds hang_pin, runs 200 frames, checks the
  metrics and the rejections.

## Measured

`godot --headless --path godot res://tests/crochet_api_check.tscn`: **23 PASS, 0 failed** (66 s; the 200 frames are most of it).
Pouch: 1380 stitches, 133 rows, 55 links, 39.8 m / 22.1 g, strap, fold after row 25; chart 1380 entries; 1250 vertices all
finite after 200 frames, the phase moved from `relax` to `hang`; 2204 triangles; 31 metric keys with the not-applicable ones
`null`; a malformed pattern is rejected with a message; an unknown load is rejected with a message. The extension builds from
`tools/build_gdext.sh` (needs `godot --headless --path godot --import` once after a rebuild). The crochet ctest subset passes
10/10 after the refactors (757 s).
