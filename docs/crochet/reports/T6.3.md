# T6.3 — Metrics (§7.5)

## What was built

* `crochet/metrics.hpp`, `crochet_metrics.cpp` (new): `computeMetrics(MetricsInput)` -> `Metrics` with `toJson()`. Inputs: the
  model, graph and layout report, the yarn, and up to three geometry states (zero-g relaxed, settled hanging, settled
  loaded), the solver-health counters of the runs and the load/fit data. The decisions (what each number means exactly)
  are the header comment of `metrics.hpp`.
* `test_crochet_metrics.cpp` (new): the 90 degree fold, the strain of a stretched strap, and every key on a real hung
  pouch.
