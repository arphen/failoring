  `box:LxWxH_mm:kg`), `fitCheck` (rest inside of the bag vs the load), `RigidLoad` (kinematic descent at 5 cm/s, then

* `test_crochet_scene.cpp` (extended): §7.4 test 1 (strap, analytic), test 2 (force balance), test 4 (fit check).

## Decisions

* **Coupling.** Per the plan: the force on the box is `m g + sum(-f_i n_i)` over cloth vertices with a positive rigid
  contact force that are nearer to the box than to the peg; `v += dt F/m; v *= exp(-c dt); |dc| <= 2 mm/frame`;
  `setPose` + `setColliderMotion`. **The plan's damping c = 8/s does not settle**: on the pouch with a 0.3 kg box the box
  bobs +-2 cm with the contact force swinging 0.7-8 N around a 2.9 N weight for 1500 frames (the cloth + strap is a
  soft spring and the explicit coupling lags). c = 30/s still bobs, **c = 80/s settles smoothly** (contact -> 2.96 N
  = weight): default 80/s, `setDamping` exposes it, and the damping-8 mutation fails the test.
* **Newton budget 60** once a load is in (30 left 8 % of the substeps at the cap; 60 has 0 of 2104).
* **Corner radius** 10 mm only where the thickness allows it (a rounded box needs r < half its thickness):
  `min(10 mm, 0.9 x half thickness)`, i.e. 5.1 mm for the MBA13 (11.3 mm thick).
* **Fit check** on rest values: inner width = half the rest circumference of the mouth (a round: the last round; a folded
  piece: twice the width of one mouth row); inner depth = the layout's rest depth (revolve height / folded half height);
  `fits = false` when width or height ratio > 1.05, `tight` within 0.95..1.05.
* **Pin reactions** = gradient of the potential energy of the constraints at each pinned vertex (central differences,
  1e-6 m): the contact forces of a resting load are external to it, so their y sum is the weight of cloth + load.
* **Mesh strip width.** The mesh has one vertex per stitch top, so a strip of n stitches is n-1 cells wide: the half stitch at
  each free edge carries no load. Test 1's analytic uses the load-bearing mesh width `(n-1) w`. With the full
  fabric width `n w` the same load would give a 4 % smaller elongation in the stiff branch (63.7 mm simulated vs
  61.3 mm), and up to 25 % in the soft branch (a 5-wide strap under a phone). OPEN: a free-edge half-cell correction
  (stiffer boundary triangles) would remove it; not done here, listed in BOARD.md.
