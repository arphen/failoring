## Idea entries from the research report (verbatim)
Source: "Cloth and crochet simulation ideas.md" (2026-10-13). Payoff, difficulty and cost figures there are the researchers' estimates, not measurements on this code.

### T1. Virtual test bench and a three-test real-swatch protocol
*Sources: materials note (ideas 1, 15, 16, 4), haptics note (KES panel, test cards), Godot note (none).* **Outline.** One-click scripted tests on the existing core: cantilever bending length, Cusick-style drape coefficient and fold count, strip stretch, pinch-release spring-back, optionally a KES-style readout (bending B, shear G, tensile slope, weight, thickness, friction) ([KES overview](https://www.fibre2fashion.com/industry-article/4645/kawabata-evaluation-system-for-fabric)). Real side: fit on hanging-strip/cantilever (three bias angles) and a hanging-weight strip, then validate on a phone-photographed drape coefficient that is never fitted. A 2025 study found phone-photo drape coefficient statistically indistinguishable from the Cusick method, most stable at 22 cm camera height and about 980 lux, but it still used a commercial Cusick meter, so a fully home rig is untested ([MDPI](https://www.mdpi.com/2673-7248/5/4/63)). Add a `validated` flag and a reality-gap column to `fabrics.json`. Seeding presets from published data (Wang et al. 2011, 10 fabrics ([PDF](https://escholarship.org/content/qt7g35q2x7/qt7g35q2x7.pdf)); Fabric-101 ([arXiv 2609.13707](https://arxiv.org/abs/2609.13707)); Sperl's industrial knit database) is a weeks-long prior-setting task with **unconfirmed licences**.
**Assessment.** Payoff high; difficulty days. Risks: the KES hand-value names and weighting formulas are [UNVERIFIED] and need a textile source before coding; drape coefficient is insensitive to anisotropy and stretch; fold count is noisy (use three specimens); Ru et al. 2025 stress that real fabrics have no ground-truth parameters, so only held-out behaviour is a valid check ([arXiv](https://arxiv.org/html/2503.16310v1)). The Peirce relation G = w c^3 for bending length was not re-verified against ISO 9073-7 (the standard text was not read). The docs' existing test suite (cantilever, drape) is the starting point; the docs report drape coefficients for nine presets (silk 36 % to canvas 93 %) as not validated against measured cloth.


### T2. Bias-strip check of orthotropic bending
Cut 4 cm strips at 0/45/90 degrees, push over a table edge, photograph, fit Bu, Bv and the 45-degree value (Wang et al. 2011 protocol, which fits a nonlinear curvature-force curve; Failoring's is linear). This tests the docs' warning that bending anisotropy above about 1:5 is under-represented by the hinge model. If the check fails, the researchers' fallback is a shape-operator bending energy as in Bolt ([arXiv](https://arxiv.org/pdf/2504.17614)); run the experiment before any rewrite. Payoff high for wovens, difficulty days; moisture, ironing and ageing change strips.
